# موقع نافذة غرفة حالة التعليم والتدريب

هذه نسخة أولية جاهزة للنشر، وتتكون من:
- index.html: الصفحة الرئيسية
- style.css: التصميم المتجاوب
- script.js: التفاعل والبحث والنموذج

## النشر
يمكن رفع الملفات الثلاثة إلى أي استضافة مواقع ثابتة.
يجب أن يكون index.html في المجلد الرئيسي للموقع.

## قبل الإطلاق الرسمي
1. استبدال الأرقام التجريبية بالبيانات الفعلية.
2. ربط أزرار التقارير بملفات PDF أو صفحات التقارير.
3. ربط نموذج التواصل بخدمة استقبال فعلية.
4. إضافة الشعارات الرسمية وفق النسخ المعتمدة.
5. ربط نطاق خاص إذا رغبتِ.

ملاحظة: هذه النسخة تعمل محليًا بدون قاعدة بيانات، لذلك نموذج التواصل تجريبي إلى أن يتم ربطه بخدمة خلفية.
